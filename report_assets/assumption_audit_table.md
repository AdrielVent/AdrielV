# Assumption Audit Table — Preliminary Plate-Fin Heat Sink

> **Scope:** Preliminary thermal screening assumptions for the selected plate-fin concept.  
> **Note:** These assumptions are plausible first-pass engineering inputs, not validated facts. They must be confirmed during prototype testing.

| Assumption | Value used | Why it was used | Risk if wrong | How to verify in prototype test |
|---|---|---|---|---|
| 1) Steady-state heat load | **100 W** | Matches Project B design input and sets the required thermal load capacity. | If actual load profile differs (peaks/transients >100 W), chip temperature may exceed predicted values even if steady-state model passes. | Use an instrumented heater or powered chip emulator with logged power; run steady and transient profiles; compare measured temperature response to model. |
| 2) Ambient air temperature | **25 °C** | Baseline lab-condition reference for early comparison of concepts. | Warmer real ambient (e.g., enclosure heating) reduces thermal margin directly and can invalidate pass/fail conclusions. | Test in controlled chamber across expected ambient range (e.g., 25–40 °C); record inlet air temperature near heat sink. |
| 3) Convective heat transfer coefficient, h | **65 W/m²·K** | First-pass forced-convection estimate used to compare geometry options consistently. | If true h is lower due to flow maldistribution, blockage, or fan underperformance, required area increases and predicted temperatures are optimistic. | Measure airflow and pressure drop; infer or fit effective h from calorimetric test data and surface/air temperature measurements. |
| 4) Aluminum thermal conductivity, k | **205 W/m·K** | Representative value for common aluminum alloys used for preliminary thermal conduction estimates. | Actual alloy/temper/finish or elevated temperature effects can reduce k, increasing base temperature gradient and R_total. | Confirm material grade from certs; optionally test coupon conductivity or back-calculate effective k from thermal test with known boundary conditions. |
| 5) Thermal interface thickness | **0.0001 m (0.1 mm)** | Practical nominal bondline thickness for initial contact resistance estimate. | Thicker real bondline significantly increases interface resistance and chip temperature. | Use pressure-sensitive film/cross-section metrology on assembled stack; verify bondline thickness distribution at operating clamp load. |
| 6) Thermal interface conductivity | **3.0 W/m·K** | Typical mid-range value for common thermal interface materials in early-stage modeling. | If actual TIM conductivity is lower (or degrades with aging/pump-out), contact resistance rises and long-term performance drifts. | Use vendor data plus incoming QC; perform thermal resistance A/B test with production TIM and aging/thermal cycling. |
| 7) Uniform base temperature (simplifying assumption) | **Assumed approximately uniform at model level** | Simplifies fin-efficiency and area-based calculations for rapid concept screening. | Real spreading resistance can create local hot spots near heat source; model may underpredict peak junction temperature. | Install multiple thermocouples/IR mapping on base; compare measured gradients to simulation/analytical spreading model. |
| 8) Negligible radiation | **Radiation omitted** | At moderate temperatures, forced convection is often dominant; omission simplifies first-pass model. | If airflow is weak or surface emissivity is high, radiation may be non-negligible; omission can bias model either way depending on calibration method. | Compare tests in low-flow vs forced-flow regimes; estimate radiative contribution using emissivity measurements and surface temperature data. |
| 9) Minimum fin spacing constraint | **2.0 mm minimum** | Screening guardrail for manufacturability/flow access and to avoid overly restrictive channels. | If manufacturing cannot hold spacing or fouling occurs, airflow may drop; if spacing could be tighter reliably, performance/mass trade space may be missed. | Validate manufacturability with sample process capability study (Cp/Cpk) and inspect produced fin gaps; test pressure drop sensitivity to spacing variation. |
| 10) All heat exits through heat sink fins/base | **100% via sink path** | Conservative bookkeeping simplification for lumped resistance model. | Real systems may have parallel heat paths (PCB, package, fasteners); ignoring them can misestimate sink-only performance attribution. | Build full thermal balance test (input power vs sink dissipation, nearby structure temperatures); use guarded setup or calibrated simulation to quantify parallel paths. |

## Audit Outcome (Preliminary)

- These assumptions are suitable for **concept comparison and early sizing only**.
- Final design release should require correlation between model and prototype data, including uncertainty bounds and repeatability checks.
